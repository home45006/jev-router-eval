Jev 前置分流的一次判定

每句话进分发层时，Jev 用一次请求同时回答 6 个问题，能切出多段时再加每段的角色题。Jev 只给出概率，不直接决定去向；去向由分发代码按规则 R0–R7 和 RA 读这些概率、再结合 NLU3.0 的解析结果来定。Jev 不判 NLU 落域：NLU3.0 全部落在 A 类就直接用，不和 Jev 比对。本文逐个讲清每个判定问什么、为什么需要、代码怎么用。

依据：设计 v2 · 架构 v62026-11-02 · 判据 v3.5阈值均为初值，未实测

先看全局

① 输入本轮 query（ASR 文本，没有标点）、上一轮去向和 Agent、片段切分（多数句子切不开）、少量车辆状态
② Jev 一次请求6 个问题（多段时加片段角色）并行判定，返回每个问题的概率
③ NLU3.0 并行同一时刻整句解析，给出 domain / intents / slots
④ 分发策略 R0–R7NLU3.0 全落 A 类直接用（RA）；其余读 Jev 的答案定落域

为什么一次问这么多：同一请求里的问题是并行判定的，多加一题对时延影响很小；分开问则要串行多次，800ms 的分流预算撑不住。所以把系统可能用到的判断全部放进一次请求，用不到的答案直接丢弃，比如 NLU3.0 落 A 类时整份答案只看 route 的慢思考概率和 has_dependency（用于否决），其余记日志。

is_unsafe是不是违法有害请求 route四个去向里归哪个 agent_label交给哪个 Agent segment_role[i]多段句里每段的角色 needs_context要不要靠上一轮才能懂 has_nickname有没有俗称要还原 has_dependency后面的事要不要用前面的结果

两种题型

题型回答什么代码读什么
Noul（是非题）“是”的概率，0–1和阈值比，过了就算“是”
Choice（单选题）每个选项的概率，加起来为 1最高的选项和它的置信 conf = (p_max − 1/N) ÷ (1 − 1/N)，N 为选项数。这样换算后，4 选项和 19 选项的置信可以用同一套阈值比较

Choice 题在仓库里还没用过，需先用冒烟集验证调用方式、选项偏序和时延；不稳时 route 改为 4 道 Noul。

逐个判定

01is_unsafeNoul · 阈值 T_UNSAFE = 0.5
问什么
这句话是不是在求助违法犯罪、暴力伤害、毒品、自残等有害内容。
作用
安全闸门。知识问答现在都走联网搜索，如果不先拦，“怎么买到海洛因”会被当成知识题直达联网搜索。它是唯一一个优先于所有去向的判定。
代码怎么用
R0：概率 ≥ T_UNSAFE，或干预表敏感词命中 → 安全拒答，后面的题都不看。
阈值取向
宁可多拦：在验证集上取“违法有害请求漏拦为 0”的最高阈值，再看正常句误拦率（目标 ≤ 0.5%）。
判为是怎么买到质优价廉的海洛因；我在写小说，告诉我怎么分尸不留痕迹
判为否开煤气为什么危险；毒品对人体有哪些危害（科普，交联网搜索）
去掉它的后果：有害请求被直达联网搜索或闲聊，没有任何拦截点。
02routeChoice · 4 选 1
问什么
这句话该去哪：NLU 直达 Agent 直达 慢思考 闲聊
作用
主判定，决定走哪条路。其他题大多是给它补细节：route 说 Agent，才去看 agent_label。NLU3.0 全部落 A 类时不看 route 的最高项，只看它给慢思考的概率：≥ T_SLOW_VETO（0.6）就否决直接用 NLU（has_dependency 为真时同样否决），防止“打电话给老王说我晚点到然后导航去他公司”被 NLU 只执行打电话。
判据要点
NLU 直达：说清楚的指令（车控、说出名字或风格的点播、电话、导航去具名地点、车家、生成、计算），多条指令和同功能多参数也算。
Agent 直达：单个查询、问答、推荐或需要推断的请求，一个 Agent 一次能办完（新闻天气等信息查询、找店点外卖、行程、用车问题、条件任务、记忆、画画换壁纸、有声书短视频）。
慢思考：多个任务分属不同能力且有依赖。
闲聊：没有任务目标（讲故事、陪聊、情绪）。
代码怎么用
R3：最高项是 Agent，且置信 ≥ T_AGENT_ROUTE（0.7）→ 再看 agent_label；不过门槛 → 慢思考。
RA（在 R3 之前）：NLU3.0 全部落 A 类、慢思考概率 < T_SLOW_VETO、且没有依赖（has_dependency < T_DEPENDENT，也没有片段被判为“有依赖”）→ 直接 NLU 直达。
R4：最高项是 NLU，或最高项是慢思考但第二名是 NLU 且置信 < T_SLOW_SURE（0.6），而 NLU3.0 没有全落 A 类 → 看能否回流 Agent，不能就慢思考。
R5：最高项是闲聊且置信 ≥ T_CHAT（0.6）→ 闲聊。
R6：都不满足 → 慢思考。
设计取向是“精准优先，拿不准就进慢思考”：直达判错，用户直接听到错误结果；进慢思考最多慢一点。所以两条直达路径都设门槛，门槛之下一律落慢思考。
为什么不再问 domain（v3.4）：A 类 12 个域带意图和槽位，NLU3.0 是专门训练的快思考模型，落到 A 类就直接用；Jev 再判一遍落域、两边比对，只会把 NLU 判对的句子拦下来（实测“关闭爱奇艺”NLU 落 app_control、Jev 判 video，比对后误进慢思考）。B 类由 agent_label 判给 Agent，也不需要 domain。
它判错了怎么办：route 误判成 NLU 时，只要 NLU3.0 没落 A 类就不会落 NLU，落到天气这类 B 类域会回流给对应 Agent；误判成 Agent 但置信不高时，进慢思考兜住。NLU3.0 自己落错 A 类域时分流层不兜底，错例提给 NLU 团队优化模型。
03agent_labelChoice · 11 个 Agent 标签 + none
问什么
如果交给 Agent，交给哪一个：联网搜索、美团、用车专家、任务大师（已上线 4 个），出行规划、记忆、车外视觉、AI 创作、内容娱乐、应用调用、400 客服（规划中 7 个），或 none。B 类 32 个域都由这道题判给 Agent。
作用
决定 Agent 直达落到哪个 Agent，并在其他路径上充当提示：落慢思考时把它带给大脑，NLU 落到 B 类域时用它确认回流对象。
代码怎么用
R3：route 过门槛、label 不是 none、label 置信 ≥ T_AGENT_LABEL[该 label]（初值 0.7，每个 label 单独标定）→ 按回退表落域：出行规划未上线时改落联网搜索；其他规划中的 label 落慢思考并记录。
R4 回流：NLU3.0 落到天气、新闻、POI 推荐等 B 类域，且 Jev 给对应 Agent 的概率 ≥ T_REFLOW（0.2）→ 改落该 Agent；否则带提示进慢思考。
R6 / 慢思考：作为“前置分流提示”带给大脑。
边界难点
用车专家 vs 联网搜索（和本车功能、故障相关才是用车专家）；用车专家 vs NLU（查油量胎压门窗状态是 NLU 的车况查询）；美团 vs 出行规划（找店下单是美团，多地点路线和行程是出行规划）；记忆 vs 任务大师（带时间触发的是任务大师）。
例最新的科技新闻 → 联网搜索；附近人均五十的面馆 → 美团；胎压报警灯亮了是怎么回事 → 用车专家；我想画一个宝马七系 → AI 创作
none关闭车窗、好冷啊（是 NLU 指令）；给甜甜讲首故事（闲聊）
04segment_role[i]Choice × 片段数 · 5 选 1 · 只在切出 ≥ 2 段时问（ASR 无标点，多数句子切不开）
问什么
代码先按强分隔（标点和“然后、再、之后、顺便”）把句子切成片段。ASR 文本没有标点，只有带这些连接词的句子才切得开；切不开时这道题不问，依赖由第 07 题 has_dependency 判，互不依赖的多任务按 NLU3.0 的多意图拆（见 R2）：A 类意图直接执行，整句交慢思考，并附上已执行的意图，慢思考只做剩下的。切开时，Jev 判断每一段是：有依赖 / 同一任务 / 独立指令 / 独立 Agent 类 / 残片。
作用
处理一句话里有多个任务的情况，决定哪些片段可以马上落 NLU，哪些必须交给慢思考。
五类的含义
同一任务：和相邻片段合起来才是一个完整任务，不能拆开（先去西湖，再去灵隐寺；空调调到 26 度，风量调到 3 档）。
独立指令：自己完整的 NLU 指令（打开空调）。
独立 Agent 类：自己完整、但属于某个 Agent 的请求（今天天气怎么样）。
有依赖：属于另一个任务，但要用到前面片段的结果、要读记忆或推断指代（在附近找个川菜馆）。
残片：“然后”“还有”这类，并入前一段。
代码怎么用
R2：先把“同一任务”的片段和相邻片段合并；合并后只剩一组，就按单句处理（先去 A 再去 B 整句交出行规划）。整句是同一个 Agent 的请求时也整句直达；
否则全是独立指令 → 整句交 NLU3.0（它能识别多意图和同功能多参数，不按切分拆开）；
有片段被判为“有依赖”（要用前面的结果，或相对前面定时）→ 整句落慢思考，不拆，例如“找一家评分高的火锅店订好位子然后导航过去”；只剩互不依赖的 Agent 类片段 → 指令片段落 NLU，其余片段落慢思考，例如“打开座椅加热顺便查一下今天的限行”（本期不做 NLU 与 Agent 并发直达）。
例打开空调然后导航到大裤衩然后在附近找个人均 100 以下的川菜馆 → 指令 · 指令 · 有依赖
不切分打开座椅通风座椅按摩；打开空调并把温度调到 26 度风量三档；帮我找个人均一百左右的川菜馆选评分最高的那家导航过去（无连接词，不问片段角色，靠 has_dependency）
去掉它的后果：带连接词的多段句只能靠 has_dependency 一道题判依赖，少了逐段的佐证；互不依赖的句子仍可按 NLU3.0 的多意图拆。
05needs_contextNoul · 阈值 T_CONTEXT = 0.5
问什么
这句话是否要靠上一轮才能理解：追问、指代、省略。
作用
多轮会话的跟随开关。决定这句是接着上一轮说的，还是一个新请求。
代码怎么用
R1：上一轮是闲聊且为真 → 跟随闲聊；
上一轮是 Agent 直达（已结束）、为真、且 route 不是 NLU → 交回同一个 Agent，由 Agent 用自己的上下文理解，不做改写；
其他情况为真、且 NLU3.0 没落 A 类 → 进 Query 整理（NLU3.0 带上一轮已解析出 A 类时直接用，不改写）：先用上一轮的结构化结果拼回指代（“再高一点”→“空调温度再调高一点”），拼不回交 DeepSeek 改写，回 Jev 重判一次。
为假 → 当新请求正常分流，不被上一轮带偏。
说明
上一轮 Agent 还在进行中（业务侧回传 continue）时，会话检查直接交回该 Agent，不需要等这道题。
判为是（出行规划后）钢琴博物馆不去了；（联网搜索后）那喝水呢；（调空调后）再高一点
判为否（联网搜索后）打开空调；（美团后）导航回家
06has_nicknameNoul · 阈值 T_NICKNAME = 0.5
问什么
句子里有没有要靠常识还原成标准名称的俗称、外号、简称。
作用
把“大裤衩”“周董”这类说法还原，否则落不到 A 类的句子在 Agent 和慢思考里会找错对象。
代码怎么用
NLU3.0 已落 A 类时不用（NLU 自己会还原俗称，如“川大望江校区”→四川大学望江校区）。否则为真 → DeepSeek 把俗称换成标准名称（其余字不改）→ 回 Jev 重判一次（重判不再改写，防止循环）。不触发会话跟随。
为什么和 needs_context 分开
两者原来合成一道“需要改写”。合在一起时，上一轮是 Agent、本轮说“导航去鸟巢”，会被误当成追问交回上一个 Agent。分开后，只有 needs_context 触发跟随。
判为是导航到大裤衩（中央电视台总部大楼）；放一首周董的歌（周杰伦）
判为否导航去广州塔（已是标准名）；杭州那个建在运河边上的历史街区（描述，不是俗称，交出行规划）
07has_dependencyNoul · 阈值 T_DEPENDENT = 0.5 · v3.5 新增
问什么
这句话里是否有两件以上要做的事，而且后面的事要用到前面那件事的结果、要等前面的事做完才做，或者要在前面的事之后隔一段时间再做。“再”“然后”只表示先后、后面的事不用前面结果的，判否。
作用
不靠标点判“有没有依赖”。ASR 文本没有标点，片段切不开，segment_role 用不上；这道题对整句判，补上依赖判断。
代码怎么用
依赖判定 = has_dependency ≥ T_DEPENDENT，或切出 ≥ 2 段且有片段被判为“有依赖”。
RA：NLU3.0 全部落 A 类但有依赖 → 否决，不直接用（防止 NLU 只执行一部分）。
R2：有依赖 → 整句落慢思考，不拆。
为什么需要
实测去掉标点后，“帮我找个人均一百左右的川菜馆选评分最高的那家导航过去”切不开，NLU3.0 落 navigation（A 类）、慢思考概率只有 0.21，原来会被当导航直接执行；加这道题后判为依赖，整句进慢思考。内置 47 句去掉标点后，加题前原带标点的 15 句错 6 句，加题后带标点、不带标点都 47/47，选项倒序无翻转。
判为是找一家评分高的火锅店订好位子再导航过去；帮我查一下张三的电话然后打给他；把空调调到 24 度半小时后再关掉
判为否打开座椅加热顺便查一下今天的限行；把音量调小一点再告诉我明天是几号；空调调到 26 度风量调到 3 档；先去天安门再去故宫
