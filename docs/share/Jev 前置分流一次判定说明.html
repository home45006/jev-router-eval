Jev 前置分流的一次判定

每句话进分发层时，Jev 用一次请求同时回答 7 个问题。Jev 只给出概率，不直接决定去向；去向由分发代码按规则 R0–R7 读这些概率、再结合 NLU3.0 的解析结果来定。本文逐个讲清每个判定问什么、为什么需要、代码怎么用。

依据：设计 v2 · 架构 v62026-10-29阈值均为初值，未实测

先看全局

① 输入本轮 query、上一轮去向和 Agent、片段切分、少量车辆状态
② Jev 一次请求7 个问题并行判定，返回每个问题的概率
③ NLU3.0 并行同一时刻整句解析，给出 domain / intents / slots
④ 分发策略 R0–R7只读与去向相关的答案，定落域；其余答案记日志

为什么一次问 7 个：同一请求里的问题是并行判定的，多加一题对时延影响很小；分开问则要串行多次，800ms 的分流预算撑不住。所以把系统可能用到的判断全部放进一次请求，用不到的答案直接丢弃，比如 route 判为 NLU 时就不读 agent_label。

is_unsafe是不是违法有害请求 route四个去向里归哪个 domain在哪个 NLU 入口域 agent_label交给哪个 Agent segment_role[i]多段句里每段的角色 needs_context要不要靠上一轮才能懂 has_nickname有没有俗称要还原

两种题型

题型回答什么代码读什么
Noul（是非题）“是”的概率，0–1和阈值比，过了就算“是”
Choice（单选题）每个选项的概率，加起来为 1最高的选项和它的置信 conf = (p_max − 1/N) ÷ (1 − 1/N)，N 为选项数。这样换算后，4 选项和 20 选项的置信可以用同一套阈值比较

Choice 题在仓库里还没用过，需先用冒烟集验证调用方式、选项偏序和时延；不稳时 route 改为 4 道 Noul。

逐个判定

01is_unsafeNoul · 阈值 T_UNSAFE = 0.5
问什么
这句话是不是在求助违法犯罪、暴力伤害、毒品、自残等有害内容。
作用
安全闸门。知识问答现在都走联网搜索，如果不先拦，“怎么买到海洛因”会被当成知识题直达联网搜索。它是唯一一个优先于所有去向的判定。
代码怎么用
R0：概率 ≥ T_UNSAFE，或干预表敏感词命中 → 安全拒答，后面的题都不看。
阈值取向
宁可多拦：在验证集上取“违法有害请求漏拦为 0”的最高阈值，再看正常句误拦率（目标 ≤ 0.5%）。
判为是怎么买到质优价廉的海洛因；我在写小说，告诉我怎么分尸不留痕迹
判为否开煤气为什么危险；毒品对人体有哪些危害（科普，交联网搜索）
去掉它的后果：有害请求被直达联网搜索或闲聊，没有任何拦截点。
02routeChoice · 4 选 1
问什么
这句话该去哪：NLU 直达 Agent 直达 慢思考 闲聊
作用
主判定，决定走哪条路。其他题大多是给它补细节：route 说 NLU，才去看 domain；说 Agent，才去看 agent_label。
判据要点
NLU 直达：说清楚的指令（车控、说出名字或风格的点播、电话微信、导航去具名地点、车家、生成、计算），多条指令和同功能多参数也算。
Agent 直达：单个查询、问答、推荐或需要推断的请求，一个 Agent 一次能答完（新闻、天气、即时信息、用车问题、条件任务、记忆、找歌找片、找店和行程、只说感受）。
慢思考：多个任务分属不同能力且有依赖。
闲聊：没有任务目标（讲故事、陪聊、情绪）。
代码怎么用
R3：最高项是 Agent，且置信 ≥ T_AGENT_ROUTE（0.7）→ 再看 agent_label；不过门槛 → 慢思考。
R4：最高项是 NLU，或最高项是慢思考但第二名是 NLU 且置信 < T_SLOW_SURE（0.6）→ 看 NLU3.0 能不能接住。
R5：最高项是闲聊且置信 ≥ T_CHAT（0.6）→ 闲聊。
R6：都不满足 → 慢思考。
设计取向是“精准优先，拿不准就进慢思考”：直达判错，用户直接听到错误结果；进慢思考最多慢一点。所以两条直达路径都设门槛，门槛之下一律落慢思考。
它判错了怎么办：route 误判成 NLU 时，R4 还有三道关（入口白名单、结构完整、域一致），落到天气这类非入口域会回流给对应 Agent；误判成 Agent 但置信不高时，进慢思考兜住。
03domainChoice · 19 个入口域 + 非入口（20 选项）
问什么
如果这是一条 NLU 指令，它属于 19 个入口域里的哪一个；都不是就选“非入口”。
作用
校验 NLU3.0 落的域对不对。NLU3.0 不输出置信度，自己判错了不会说；Jev 的 domain 分布是唯一能用来复核它的依据。同时，两边不一致的比例是监控指标，能最早发现哪一边漂了。
代码怎么用
只在 R4（走 NLU 直达）时读：
· Jev 选“非入口” → 不落 NLU，进慢思考；
· NLU3.0 的 domain 与 Jev 最高项相同或是近邻对（如 intelligent_car_control↔global_control）→ 通过；
· 不一致时，Jev 给 NLU 所选域的概率 ≥ T_DOMAIN_AGREE（0.2）→ 仍按 NLU 落域，否则进慢思考。
为什么只问 19 个
NLU3.0 有 45 个域，但只有 19 个作为入口；其余 26 个不会被直达执行。选项从 46 个减到 20 个，降时延，也减轻 Choice 偏向排在前面选项的问题。
例关闭前挡风玻璃加热 → intelligent_car_control；放一首稻香 → music
非入口明天苏州天气怎么样；附近有什么好吃的
去掉它的后果：NLU3.0 把“打开氛围灯”误落成 music 时没人发现，错的指令会直接执行。
04agent_labelChoice · 12 个 Agent 标签 + none
问什么
如果交给 Agent，交给哪一个：新闻、天气、联网搜索、用车专家、任务大师、记忆、音乐、影视、出行导航、自适应车控（本期上线 10 个），代办点单（shadow）、400 客服（待接入），或 none。
作用
决定 Agent 直达落到哪个 Agent，并在其他路径上充当提示：落慢思考时把它带给大脑，NLU 落到非入口域时用它确认回流对象。
代码怎么用
R3：route 过门槛、label 不是 none、label 置信 ≥ T_AGENT_LABEL[该 label]（初值 0.7，每个 label 单独标定）→ 按回退表落域：新闻、天气未接入时改落联网搜索；shadow 状态的 label 落慢思考并记录。
R4 回流：NLU3.0 落到天气、新闻、POI 推荐等非入口域，且 Jev 给对应 Agent 的概率 ≥ T_REFLOW（0.2）→ 改落该 Agent；否则带提示进慢思考。
R6 / 慢思考：作为“前置分流提示”带给大脑。
边界难点
新闻 vs 联网搜索（和新闻相关才是新闻）；用车专家 vs 联网搜索（和用车相关才是用车）；记忆 vs 任务大师（带时间触发的是任务大师）；音乐、出行导航 vs NLU（按描述找的是 Agent，说出名字的是 NLU）。
例最新的科技新闻 → 新闻；今天星期几 → 联网搜索；胎压报警灯亮了是怎么回事 → 用车专家；好冷啊 → 自适应车控
none关闭车窗（是 NLU 指令）；给甜甜讲首故事（闲聊）
05segment_role[i]Choice × 片段数 · 5 选 1 · 只在切出 ≥ 2 段时问
问什么
代码先按强分隔（标点和“然后、再、之后、顺便”）把句子切成片段，Jev 判断每一段是：有依赖 / 同一任务 / 独立指令 / 独立 Agent 类 / 残片。
作用
处理一句话里有多个任务的情况，决定哪些片段可以马上落 NLU，哪些必须交给慢思考。
五类的含义
同一任务：和相邻片段合起来才是一个完整任务，不能拆开（先去西湖，再去灵隐寺；空调调到 26 度，风量调到 3 档）。
独立指令：自己完整的 NLU 指令（打开空调）。
独立 Agent 类：自己完整、但属于某个 Agent 的请求（今天天气怎么样）。
有依赖：属于另一个任务，但要用到前面片段的结果、要读记忆或推断指代（在附近找个川菜馆）。
残片：“然后”“还有”这类，并入前一段。
代码怎么用
R2：先把“同一任务”的片段和相邻片段合并；合并后只剩一组，就按单句处理（先去 A 再去 B 整句交出行导航）。整句是同一个 Agent 的请求时也整句直达；
否则全是独立指令 → 整句交 NLU3.0（它能识别多意图和同功能多参数，不按切分拆开）；
混有 Agent 类或有依赖片段 → 指令片段落 NLU，其余片段落慢思考（本期不做 NLU 与 Agent 并发直达）。
例打开空调，导航到大裤衩，在附近找个人均 100 以下的川菜馆 → 指令 · 指令 · 有依赖
不切分打开座椅通风座椅按摩；打开空调并把温度调到 26 度风量三档（无强分隔，整句交 NLU3.0）
去掉它的后果：“打开空调，今天天气怎么样”会被整句当 NLU 执行，天气那半句丢失；或整句进慢思考，打开空调也要等规划。
06needs_contextNoul · 阈值 T_CONTEXT = 0.5
问什么
这句话是否要靠上一轮才能理解：追问、指代、省略。
作用
多轮会话的跟随开关。决定这句是接着上一轮说的，还是一个新请求。
代码怎么用
R1：上一轮是闲聊且为真 → 跟随闲聊；
上一轮是 Agent 直达（已结束）、为真、且 route 不是 NLU → 交回同一个 Agent，由 Agent 用自己的上下文理解，不做改写；
其他情况为真 → 进 Query 整理：先用上一轮的结构化结果拼回指代（“再高一点”→“空调温度再调高一点”），拼不回交 DeepSeek 改写，回 Jev 重判一次。
为假 → 当新请求正常分流，不被上一轮带偏。
说明
上一轮 Agent 还在进行中（业务侧回传 continue）时，会话检查直接交回该 Agent，不需要等这道题。
判为是（出行导航后）钢琴博物馆不去了；（联网搜索后）那喝水呢；（调空调后）再高一点
判为否（新闻后）打开空调；（音乐后）导航回家
07has_nicknameNoul · 阈值 T_NICKNAME = 0.5
问什么
句子里有没有要靠常识还原成标准名称的俗称、外号、简称。
作用
把“大裤衩”“周董”这类说法还原，否则 NLU3.0 的槽位填不准，导航、点播会找错对象。
代码怎么用
为真 → DeepSeek 把俗称换成标准名称（其余字不改）→ 回 Jev 重判一次（重判不再改写，防止循环）。不触发会话跟随。
为什么和 needs_context 分开
两者原来合成一道“需要改写”。合在一起时，上一轮是 Agent、本轮说“导航去鸟巢”，会被误当成追问交回上一个 Agent。分开后，只有 needs_context 触发跟随。
判为是导航到大裤衩（中央电视台总部大楼）；放一首周董的歌（周杰伦）
判为否导航去广州塔（已是标准名）；杭州那个建在运河边上的历史街区（描述，不是俗称，交出行导航）

7 个答案怎么组合成去向

分发代码按顺序匹配，命中即停：

规则读哪些判定结果
R0 安全is_unsafe安全拒答
R1 会话needs_context、route（+ 会话状态）跟随闲聊 / 交回同一 Agent
R2 多段segment_role、route、agent_label整句直达 Agent / 整句落 NLU / 拆分
R3 Agent 直达route、agent_labelAgent 直达 或 慢思考
R4 NLU 直达route、domain、agent_label（回流）+ NLU3.0NLU 直达 / 回流 Agent / 慢思考
R5 闲聊route闲聊
R6 剩余agent_label（作提示）慢思考
R7 落域失败业务侧回传“不支持 / 不归我”改落 慢思考 一次

has_nickname 在进入规则之前生效：为真时先还原、重判，再走上面的规则。

请求长什么样

state = {
  "query": "钢琴博物馆不去了",
  "previous_turn": {"query": "...", "route": "agent", "agent": "出行导航", "status": "end"},
  "segments": null,                       // 只有切出 ≥ 2 段时才有
  "vehicle": {"navigating": true, "playing": "music"}
}
questions = {
  "is_unsafe":     Noul(...),
  "route":         Choice(options=["NLU直达","Agent直达","慢思考","闲聊"], ...),
  "domain":        Choice(options=NLU_ENTRY_19 + ["非入口"], ...),
  "agent_label":   Choice(options=AGENT_LABELS + ["none"], ...),
  "needs_context": Noul(...),
  "has_nickname":  Noul(...),
  "segment_role_0": Choice(options=["有依赖","同一任务","独立指令","独立Agent类","残片"], ...)   // 多段时才有
}

每道题的说明文字（instructions）和判据（criteria / 选项说明）写在 criteria_v3.json 里，放云端配置中心，可热更新；阈值也在配置里，按验证集标定。
