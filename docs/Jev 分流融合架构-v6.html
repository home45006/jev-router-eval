Jev 分流融合架构

本架构只负责分发和落域，不负责业务。Jev 与 NLU3.0 在分发层并行起跑，一次请求判定去向并给出落域结果：说清楚的指令走 NLU3.0 直达（19 个入口域），查询、问答、推荐和需要推断的单个请求走 Agent 直达（本期 10 个 Agent），跨能力且有依赖的多任务和 NLU3.0 接不住的句子进慢思考，没有任务目标的进闲聊，违法有害请求安全拒答。出口之后的执行、仲裁和下发由业务侧负责。

分发策略

规则条件去向
R0 安全is_unsafe 达到阈值，或干预表敏感词命中安全拒答
R1 会话慢思考占用会话；上一轮 Agent 返回 continue；上一轮 Agent 已结束而本轮 needs_context 为真且不是新指令；上一轮闲聊且是追问慢思考 / 同一 Agent / 闲聊
R2 多段整句是同一个 Agent 的请求（先去 A 再去 B）→ 整句直达；否则全是指令 → 整句交 NLU3.0；混有 Agent 类或依赖片段 → 指令段 NLU 直达，其余进慢思考Agent / NLU / 拆分
R3 Agent 直达route = Agent 且 route、label 置信都过门槛；按回退表（新闻、天气 → 联网搜索）；shadow 的 label 进慢思考Agent 直达，不过门槛则 慢思考 带提示
R4 NLU 直达route = NLU，或在 NLU 与慢思考之间拿不准。每个 intent：在 19 个入口域内、不是 other、intent 和必填槽位齐全、与 Jev 的 domain 一致（或 Jev 给该域概率够高）。落非入口域 → 回流对应 Agent；other → 改写重判一次NLU 直达 / 回流 Agent / 慢思考
R5 闲聊route = 闲聊且置信过门槛闲聊
R6 剩余以上都不满足慢思考，带 Agent 标签和 NLU 结果作提示
R7 落域失败快思考落域失败转慢思考，分两种：① 落域前——R3 门槛不过、R4 的结构 / 域一致 / 回流检查不过、other 改写重判后仍接不住；② 落域后被拒——业务侧回传“不支持 / 不归我”（NLU 执行层不支持该 intent，Agent 判定请求不属于自己）。被拒的同一句只改落慢思考一次，不再回分流，避免来回弹慢思考，带原落域结果和被拒原因作提示

阈值、入口白名单、域 → Agent 回流表、label 回退表、各 Agent 的 on / shadow / off 都放云端配置中心。止血：分钟级加干预表或把 label 切到 shadow；小时级改判据、回放、灰度。

已定与待定

已定 · 归属规则

大模型 agent 业务标签都走 Agent 直达；新闻相关 → 新闻；天气 → 天气；其余即时信息和非用车知识问答 → 联网搜索；用车相关 → 用车专家；条件任务 → 任务大师；记忆调用 → 记忆；有情知音按闲聊处理。

已定 · NLU3.0

本期接入；19 个入口域；不输出置信度，用结构信号和 Jev 的 domain 分布校验；能识别无标点多意图和同功能多参数。

已定 · 架构补充

安全拒答、Agent 会话跟随、非入口域回流、domain 校验前移到分发层、片段角色五类、改写拆成“依赖上文”和“俗称”两道。

待定 · NLU3.0 接口

批量调用或离线结果、各 intent 必填槽位表、接不住时是否固定落 other。

待定 · Choice 可用性

Jev 的 Choice 调用方式、选项偏序、时延要先用冒烟集验证；不稳时 route 改为 4 道 Noul。

待定 · 两处归属

车况纯读数（还剩多少油）暂归用车专家；车外问答 outside_qa 本期进慢思考。

待定 · 标签集变更

代办点单 shadow 期间落慢思考；400 客服、三方生态 Agent 接入后加 agent_label 和判据。

待定 · 部署与合规

Jev 只提供云端 API，量产前要确认网络、时延和合规；配置中心承载判据、阈值、干预表和回流表。

待定 · 回传接口

业务侧回传 continue / end 和“落域被拒”的格式和时机。已定：被拒的由分发改落慢思考一次；业务内部的执行故障（服务超时等）由业务侧自己处理，不算落域失败。

本架构的边界：输入是 ASR 文本、会话状态和车辆状态，输出是去向和落域结果。详细规则见 design/Jev 分流详细设计（v2）；数据、映射和验收见 design/Jev 分流测试方案（v2.3）。NLU 域清单取自《车机 NLU3.0 大模型支持 Domain 清单（v13）》。V1.0 保留在 docs/Jev 分流融合架构-v5.html。分层判定方案（V6，已搁置）在 docs/archive/Jev 分流融合架构-v6-分层判定（搁置）.html。
