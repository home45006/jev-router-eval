Jev 分流融合架构

本架构只负责分发和落域，不负责业务。Jev 与 NLU3.0 在分发层并行起跑，一次请求判定去向并给出落域结果：车机能马上执行的指令走 NLU3.0 直达（v25 的 A 类 12 个入口域），查询、问答、推荐和需要推断的单个请求（含 v25 的 B 类 32 个域）由 Jev 判给 Agent 直达（已上线联网搜索、美团、用车专家、任务大师，另规划 7 个），跨能力且有依赖的多任务和 NLU3.0 接不住的句子进慢思考，没有任务目标的进闲聊，违法有害请求安全拒答。出口之后的执行、仲裁和下发由业务侧负责。

R3 Agent 直达route = Agent 且 route、label 置信都过门槛；按回退表（出行规划 → 联网搜索）；其他未上线的 label 进慢思考Agent 直达，不过门槛则 慢思考 带提示
R4 NLU 直达route = NLU，或在 NLU 与慢思考之间拿不准，但 NLU3.0 没有全部落 A 类（全部落 A 类已在 RA 直接用）：other / unknown → 改写重判一次，仍是则慢思考；chat → 闲聊；落 B 类域且 Jev 给对应 Agent 的概率 ≥ T_REFLOW → 回流该 Agent；其余慢思考NLU 直达 / 回流 Agent / 慢思考
R5 闲聊route = 闲聊且置信过门槛闲聊
R6 剩余以上都不满足慢思考，带 Agent 标签和 NLU 结果作提示
R7 落域失败快思考落域失败转慢思考，分两种：① 落域前——R3 门槛不过、R4 的回流检查不过、other 改写重判后仍接不住；② 落域后被拒——业务侧回传“不支持 / 不归我”（NLU 执行层不支持该 intent，Agent 判定请求不属于自己）。被拒的同一句只改落慢思考一次，不再回分流，避免来回弹慢思考，带原落域结果和被拒原因作提示

阈值、入口白名单、域 → Agent 回流表、label 回退表、各 Agent 的 on / off 都放云端配置中心。止血：分钟级加干预表或把 label 切到 off；小时级改判据、回放、灰度。

已定与待定

已定 · 归属规则

NLU3.0 v25 的 A 类 12 个域是真正的快思考，NLU 直达；B 类 32 个域只是落域，由 Jev 判给 Agent。信息查询（新闻、天气、即时信息、知识问答）→ 联网搜索；找店下单 → 美团；本车功能和故障 → 用车专家；条件任务 → 任务大师；记忆调用 → 记忆；有情知音按闲聊处理。（2026-11-02）

已定 · NLU3.0

本期接入；A 类 12 个入口域，B 类不作入口；不输出置信度；全部落 A 类就直接用，Jev 不判落域、不做一致性比对，只在很确定是慢思考或有依赖时否决（v3.4 / v3.5）；能识别无标点多意图和同功能多参数。

已定 · 架构补充

安全拒答、Agent 会话跟随、B 类域回流、NLU 采信前移到分发层（A 类直接用 + 慢思考否决）、片段角色五类、改写拆成“依赖上文”和“俗称”两道；ASR 无标点，依赖改由 has_dependency 对整句判（11-02）。

待定 · NLU3.0 接口

批量调用或离线结果、各 intent 必填槽位表、v25 已有 unknown 作为拒识输出。

待定 · Choice 可用性

Jev 的 Choice 调用方式、选项偏序、时延要先用冒烟集验证；不稳时 route 改为 4 道 Noul。慢思考否决对选项顺序敏感（倒序时“空调 24 度、半小时后关”的慢思考概率从 0.84 降到 0.53），T_SLOW_VETO 要在更多数据上标定。

已定 · 两处归属

车况查询（还剩多少油）和隐含车控（好冷啊）属 A 类，NLU 直达；车外问答 outside_qa 归车外视觉，未上线时进慢思考。

待定 · 标签集变更

已上线联网搜索、美团、用车专家、任务大师；其余 7 个规划中，逐个开发，上线时把 label 切到 on 并回放验证。新 Agent 接入后加 agent_label 和判据。

待定 · 部署与合规

Jev 只提供云端 API，量产前要确认网络、时延和合规；配置中心承载判据、阈值、干预表和回流表。

待定 · 回传接口

业务侧回传 continue / end 和“落域被拒”的格式和时机。已定：被拒的由分发改落慢思考一次；业务内部的执行故障（服务超时等）由业务侧自己处理，不算落域失败。

本架构的边界：输入是 ASR 文本、会话状态和车辆状态，输出是去向和落域结果。详细规则见 design/Jev 分流详细设计（v2）；数据、映射和验收见 design/Jev 分流测试方案（v2.3）。NLU 域清单取自《车机 NLU3.0 大模型支持 Domain 清单》v25（docs/NLU3.0-v25_domain清单.md；v13 仅供参考）。V1.0 保留在 docs/Jev 分流融合架构-v5.html。分层判定方案（V6，已搁置）在 docs/archive/Jev 分流融合架构-v6-分层判定（搁置）.html。
