Jev 前置分流架构

每句话只分两条路：说清楚的直接指令交给快思考模型，其余全部交给 Agent 大脑。Agent 大脑下挂各种能力，自己决定调谁。Jev 每句只调一次，只判断“交不交给快思考、要不要先改写”；线上发现落域错误时，再给 Jev 加一道纠错题来修。

第 14 版 · 2026-10-11 · 去掉独立 Agent 直达和 Jev 第二级；改写和大脑用 DeepSeek V4 Flash 非思考模式。标“估”的为估算，其余为实测

两层体验

快思考保证基础体验，智能体现在 Agent 大脑上。Agent 之间的边界太难判断，不再由前置分流来分；分流只回答一件事：这句话是不是快思考能直接处理的指令。

代码里的决策顺序

  1. 检查会话。有进行中的会话，就把这句交给 Agent 大脑。大脑返回“继续”或“结束”，本轮到此为止；返回“不归我”则会话挂起，这句从下一步开始走正常流程，处理完后会话恢复。
  2. 调 Jev 第一级。一次请求并行问 is_fast、needs_rewrite 和当前启用的纠错题。
  3. 看纠错题。有纠错题命中，按它指定的去向走（快思考，或者大脑并附上指定能力的提示）。
  4. 看 is_fast。达到阈值交给快思考；needs_rewrite 也达到阈值的，先用 DeepSeek 改写再交给快思考。没达到阈值交给 Agent 大脑。
  5. 快思考兜底。快思考拒识或置信度低于门限，交给 Agent 大脑。

Agent 大脑

大脑先理解用户要办的整件事，再自主决定调用哪些能力、按什么顺序调用。原来由分流决定的 Agent 边界，现在由大脑在调用时判断；单个能力就能办完的事，大脑只调一次。

能力形式做什么
快思考工具执行说清楚的直接指令，大脑因此拥有全部基础 NLU 能力
任务大师Agent周期性、每当某事发生就触发的长期规则，包括周期性提醒
条件任务Agent到某个时间或时机执行一次的动作或提醒；查询、删除日程
联网搜索Agent，接口未接入新闻资讯、实时信息
用车手册Agent本车功能、故障、使用建议
导航Agent，多轮靠描述找地点、规划路线、多地点行程
空调Agent按感受和场景调节温度、风量、座椅
多媒体Agent按氛围、描述找歌找片，播放和控制
美团Agent，多轮选店、点餐、下单
闲聊Agent，多轮开放问答和聊天，可接端到端语音
  • 模型：改写和大脑默认用 DeepSeek V4 Flash 非思考模式（AgentScope 里 DeepSeekChatModel.Parameters(thinking_enable=False)，即请求带 thinking.type=disabled）。复杂多步编排是否需要 V4 Pro 或思考模式，等大脑场景集测完再定。
  • 会话：大脑持有多轮会话，每轮返回继续、挂起、结束之一；超时、轮数上限、退出词由代码兜底。美团、导航这类子 Agent 的多轮对话都经大脑转达。
  • 代价：原来直达的任务大师、条件任务、用车手册等，现在都多经过一次大脑。实测 V4 Flash 非思考模式改写一句中位约 1.5 秒（GitHub 美国机房）；大脑调用一次工具至少两轮模型调用，车端时延需要单独测。

第一级判据

第一级只判断“这句话是不是快思考能直接理解的一条或几条指令”，判据从快思考的能力清单生成。

交给快思考

  • 车控、车窗座椅空调、HUD、驾驶模式、能量充电
  • 打开关闭应用和页面，音量、亮度、网络、语音设置
  • 按歌名、歌手、片名点播，也包括按风格、年代、语种点播；播放控制和收藏
  • 上一个、下一集、拜拜、退下等通用短指令
  • 导航去说得出名字的地点，导航设置，从当前位置到家、公司、目的地、途经点的距离和路况
  • 智驾和泊车、场景模式、电话、几项车辆数值查询
  • 一句话连说几条直接指令

交给 Agent 大脑

  • 问本车功能怎么用、为什么坏、状态是否正常，即使说法像指令
  • 只说感受没说指令；按氛围、歌词、剧情找歌找片
  • 靠描述找地点、多地点行程、去某个具体地名要多久；说出了出发地的两地距离和路况（家到公司还有多远）
  • 日程和提醒、带执行时间的动作（条件任务），周期性提醒和长期规则（任务大师）
  • 多条指令里有需要推断、查询、订票、带话的步骤
  • 新闻、记住个人信息、开放问答和闲聊

Jev 纠错：落域错了怎么修

上线后发现某一类句子落错了地方，不改大脑、不重训快思考，先给 Jev 第一级加一道纠错题。纠错题是一个二元问题，描述这类句子长什么样，附正例和反例；它和 is_fast 在同一次请求里作答，不增加调用次数。

例子（取自实测中判错的句子）纠错题命中后去向
山地模式时空气悬架调到便携装载模式；在自动驾驶模式下播放舒缓的音乐是否是“在某种模式或状态下自动执行动作”的长期规则？Agent 大脑，提示调用任务大师
打开自适应；关闭隐私政策；打开微信绑定是否是打开、关闭某个系统设置项或页面？快思考
  • 上线前回放：新纠错题在 13,662 条评测集和回归集上回放，报告它会改变多少句的去向、其中多少句改错了，有改错的要收窄描述。
  • 先灰度：只记录命中、不改变去向，确认线上没有误伤再启用。
  • 要退场：每道纠错题对应一类已知错误。快思考的能力清单、第一级判据或大脑的提示词修好后，就下线这道题。纠错题保持在十道以内，每道约增加一两百 token估。

已定口径

  • 日程提醒不交给快思考。语义 sheet 里 scheduleReminder 的句子全部改标：周期性的（每周三提醒我开会）归任务大师，其余（5月30日提醒我开会、明天有日程吗、删除第2个日程）归条件任务。评测集里 16 条改标，另有 128 条“条件任务 / 日程提醒”双标签的句子收为只算条件任务。
  • 说出了出发地的两地距离归大脑。语义 sheet 里 naviControl 中的“家到公司还有多远”“儿童医院到北京天信亮酒店还有多长时间”“北京天信亮酒店到五道口堵不堵”这类 22 条改标为复杂导航，交给大脑；只问从当前位置到某地的（到公司还有多远、目的地堵不堵）仍归快思考。
  • 改标在切分之后进行，句子留在原来的 dev / val / test 里；规则写在 build_dataset.py，第一级判据是 v2.4。
