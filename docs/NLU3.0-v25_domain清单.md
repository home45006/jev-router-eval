# 车机 NLU3.0 大模型支持 Domain 清单（v25，以此为准）

- 来源：《NLU3.0大模型接口使用说明1030固定版本》第六节，v25 模型训练集 `nlu_train_v25_modi.jsonl`（101,513 条）的 45 个 domain 及条数（2026-10-30 统计）
- 模型：`qwen3_nlu`（Qwen3-0.6B 全量微调，v25），接口 `http://<NLU3-v25 服务地址>/v1/chat/completions`；项目里只用 `temperature=0, top_p=0.01`
- 中文名、一句话介绍、例句沿用低版本清单 v13（`docs/NLU3.0大模型_domain清单.md`，仅供参考）；“分流处理”一列对应判据 `docs/share/criteria_v3.json`（v3.2）
- 2026-10-30 实测 945 句，模型输出过的域与本清单一致；另出现过 1 次清单外的 `similar_words`

## 与 v13 的差异

| | 域 | 处理 |
|---|---|---|
| v13 有、v25 没有 | `wechat_on_car`（车载微信）、`app_agent`（应用内智能体） | 模型不会输出；微信类请求交慢思考，应用内操作由 Jev 判给代办点单 |
| v25 新增 | `unknown`（拒识）、`row_column_position` | `unknown` 按“接不住”处理；`row_column_position` 含义待确认，暂按慢思考 |
