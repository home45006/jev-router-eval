# 车机 NLU3.0 大模型输出 Domain 清单（v25，以此为准）

- 来源：《NLU3.0 输出域清单（v25 简明版）》（`docs/nlu3/NLU3.0输出域清单_简明版_v25.md`，2026-11-02）定 44 个输出域和 A/B 分类；训练条数取自《NLU3.0大模型接口使用说明1030固定版本》第六节（v25 训练集 `nlu_train_v25_modi.jsonl`）
- 模型：`qwen3_nlu`（Qwen3-0.6B 全量微调，v25），接口 `http://<NLU3-v25 服务地址>/v1/chat/completions`；项目里只用 `temperature=0, top_p=0.01`
- 一句话介绍、例句参考低版本清单 v13（`docs/NLU3.0大模型_domain清单.md`，仅供参考）；“分流处理”一列对应判据 `docs/share/criteria_v3.json`（v3.3）
- Agent 的上线状态和规划见 `docs/Agent清单与规划.md`

## 分流原则（2026-11-02 定）

| 类 | 个数 | NLU3.0 输出 | 分流 |
|---|---:|---|---|
| A 类 | 12 | 域 + 独立意图 + 槽位 | **真正的快思考**，NLU 直达（入口域），按 intent 和 slots 执行 |
| B 类 | 32 | 域名直出，intent 与 domain 相同 | 只是落域，**由 Jev 判断**（agent_label），不靠 NLU3.0；都交给 Agent，`chat` 进闲聊，`unknown`、`other` 算接不住 |

- 信息查询（新闻、天气、日期、股票、航班火车、限行、计算、歌曲影视问答）都归联网搜索 Agent。
- 已上线的 Agent：联网搜索、美团、用车专家、任务大师；其余规划中，未上线时按回退表交给联网搜索或落慢思考，并记录命中量，作为开发排期依据。
- NLU3.0 仍与 Jev 并行起跑；它落到 B 类域时，按上表回流到对应 Agent（Jev 也要给该 Agent 足够概率）。

## 与旧版的差异

| | 内容 | 处理 |
|---|---|---|
| 入口域 18 → 12 | 去掉 `app_call`、`short_video`、`changba`、`audio_book`、`wallpaper`、`theme_gen`、`painting`、`calculator`（都是 B 类）；加上 `intelligent_car_info`、`intelligent_car_scenario`（A 类） | 前者交 Agent；车况查询、隐含车控（“车里好热啊”）改为 NLU 直达，不再走用车专家、自适应车控 |
| 简明版没有 | `row_column_position`（训练集只有 3 条） | 模型若输出，按接不住处理 |
| v13 有、v25 没有 | `wechat_on_car`、`app_agent` | 模型不会输出；微信类交慢思考，应用内操作归应用调用 Agent |
